# 🏋️ Fitness - Fitness Landing Page

A modern and responsive fitness landing page built with **HTML and CSS**.  
This project focuses on clean UI design, responsive layouts, and a professional fitness website structure.

## 🚀 Live Demo

🔗 [Live Demo] https://fitness-by-sajid.netlify.app/

## 📸 Preview

![Fitness Website Preview](fitness-resources/images/preview.png)

## ✨ Features

- 🏠 Modern fitness landing page
- 📱 Fully responsive design
- 🧭 Responsive navigation bar
- 💪 Hero section with fitness content
- 🔥 Change Your Habits section
- 🏃 Extra Mile workout section
- 👨‍🏫 Meet Our Team section
- 📋 Footer with useful links
- 🎨 Dark theme UI
- 📐 Responsive layout for:
  - Desktop
  - Tablet
  - Mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts - Inter
